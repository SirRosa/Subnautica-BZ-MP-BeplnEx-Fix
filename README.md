# Subnautica Below Zero MP 3.0.1 — Native plugin ports

Projekt portowania trzech modów na własny format wtyczek multiplayera BOT Bensona **bez BepInEx i Nautilus**.

- SnapBuilder (`Tobey.SnapBuilder.dll`)
- Building Tweaks (`BuildingTweaks.dll`)
- Craft From Containers BZ (`CraftFromContainers_BZ.dll`)

**Status:** rozpoznanie i przygotowanie testów loadera. Nie ma jeszcze gotowych portów rozgrywki. Zmiany eksperymentalne trafiają wyłącznie na oddzielne gałęzie.

Zależności i ryzyka zostaną opisane na gałęzi testowej.
